Help

Loading data

  • JSON file pick a Trello card export from disk.
  • Paste JSON open the URL in your browser, copy everything, paste it into the box and press Load pasted JSON. Most reliable.

Search

  • Looks inside every diff line and inside the author ID.
  • Case-insensitive, highlights matches in yellow.
  • While searching, all changes are auto-expanded.

Filters

  • Type a keyword and press + Add or Enter to create a filter chip.
  • Add multiple keywords at once: Cash Skins or Cash, Skins.
  • Use author:ID to filter by the author Trello member ID.
  • All keyword filters are combined with AND. Multiple author filters are combined with OR.
  • Click a tag badge on any change to add or remove it from filters.
  • Click the x on a chip to remove that filter.

Reading the diff

  • + added lines
  • - removed lines
  • meaningful real content changed.
  • formatting only whitespace or commas moved.
